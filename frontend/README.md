# CodIn Frontend

React + JavaScript + JSX frontend for CodIn.

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run preview
```

## Environment

Copy `.env.example` to `.env` and set:

```text
VITE_API_BASE_URL=http://localhost:5000
VITE_SOCKET_URL=http://localhost:5000
```

No TypeScript is used in this frontend.
